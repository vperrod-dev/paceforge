## What to improve

Pick a lane on sessions like this: either keep HR under ~136 bpm (Z1/low-Z2,
true recovery/aerobic-base work) for the full duration, or push into Z4 for
defined work blocks the way the 2026-07-29 session did (48% Z4/Z5). Sitting at
138-145 bpm for 29 straight minutes is neither — it accumulates fatigue
without the adaptation payoff of threshold work. If the intent was an easy
recovery day, cap effort noticeably lower from the start; if it was meant to
be a real session, add structure (intervals or a sustained push above 156 bpm)
so it clears Z4. No RPE logged for this one — rate it in `data/rpe.json` so
load tracking captures the real subjective cost given HR-based load likely
undercounts a sustained Z2/Z3 grind like this.
